# 栖页使用手册

栖页使用 HTML、CSS、原生 JavaScript 实现，日常使用不需要安装依赖。以下文件路径均以项目根目录为起点。

## 打开主页

直接双击当前文件夹中的 `index.html`，用 Chrome、Edge 或其他现代浏览器打开即可。不需要服务器、Node.js、安装依赖或构建步骤。

请将 `index.html`、`style.css`、`layout.css`、`core.js`、`engine-icons.js`、`app.js`、`layout.js`、`chrome-extension/bookmark-tree.js` 和 `assets/` 文件夹保留在一起。页面使用按顺序加载的普通 JavaScript 脚本，可通过 `file://` 本地文件地址运行；默认背景、字体和引擎图标均无需联网。

## 已实现

Chrome 扩展位于 `chrome-extension/`，新标签页、主页入口和工具栏按钮支持自定义 `file://` 或在线目标地址。安装、文件访问授权、启动时打开新标签页及原生主页按钮连接方法见 [扩展安装说明](../chrome-extension/README.md)。不需要服务器；旧版扩展更新后需在扩展管理页重新加载。

- 内置 18 种搜索：Google、Bing、百度、GitHub、Bilibili、知乎、豆瓣、淘宝、翻译、DuckDuckGo、Brave、Yahoo、YouTube、维基百科、Stack Overflow、npm、Google 学术和搜狗；支持网址直达。输入快捷指令加空格可切换引擎。`/` 聚焦搜索框，默认自动聚焦。
- 搜索引擎可新增、编辑、删除、设为默认、上下排序及选择是否显示在快捷栏。内置统一薄荷色图形图标，支持从 24 个品牌 / 语义图形中选择，也可保留自定义 Emoji；名称、图标选择、快捷指令和 URL 模板均本地保存，随 JSON 备份导出恢复。
- 分类网址卡片，新增、修改、删除网址；使用统一色板、底板和图形比例；新增网址可自动获取网站图标并应用灰度主题色。支持 29 种统一矢量图形及自定义上传单色化。分组新建、重命名、删除，删除分组时保留并迁移网址。
- 本地时间和日期。时钟显示 `HH:MM:SS.mmm`，毫秒字体较小，按屏幕动画帧读取系统时间；后台暂停刷新，返回时立即校准。天气初始城市为新加坡，可搜索其他城市或由用户授权浏览器定位，显示当前温度、天气、湿度与三日预报，每 30 分钟刷新。
- 待办增删、勾选、完成进度和清理；便签输入即保存。
- 25 分钟专注、5 / 15 分钟休息，暂停、继续、重置。运行中计时使用截止时间，刷新或切到后台后继续准确计算，完成时显示提示并尝试声音提醒。
- GitHub 最近 30 天创建的高星项目（按照总星数排序，不冒充 Trending）；RSS / Atom 订阅。
- 三套本地矢量风景、图片和视频壁纸上传；图标大小、每行数量、面板底色强度、深浅色与跟随系统；小组件显示控制。手机和平板响应式布局。
- 两种布局：默认显示独立的时钟日期、搜索框和页面底部的 Dock 快捷图标；右键只打开菜单，选择“展开完整主页”才切换模式。搜索交互时背景模糊、搜索框轻微放大并提高背景不透明度；时钟区域保持清晰、位置不变。自定义右键菜单提供搜索编辑、网址管理、壁纸和设置操作。
- JSON 备份导出 / 导入，包含网址、图标、待办、便签、偏好和自定义壁纸。导入先校验，再由用户点击确认替换；拒绝危险网址、无效数据和超限文件。

## 导入浏览器书签

扩展 1.3.0 支持读取浏览器原有书签。在扩展设置中点击「读取浏览器书签」、授权并勾选后下载导入文件，再到主页「个性化设置 → 数据与备份 → 导入浏览器书签」选择文件、预览并确认追加。已有网址、便签、待办和设置保留，重复网址自动跳过。每次最多选择 500 项，并以主页剩余容量为准。

扩展与主页均按文件夹树预览，可勾选整个文件夹或单个书签，支持部分选中。导入时可选择分组，并保留浏览器原有文件夹层级；Dock 中可以进入子文件夹，点击路径返回上级。也可关闭「保留文件夹层级」，直接导入 Dock。书签仅在本地转移，不自动访问导入的网址。详细步骤见 [扩展说明](../chrome-extension/README.md)。

Dock 文件夹右键可选择「删除文件夹及内容」，包含所有子文件夹和网址；也可在整理窗口中解散文件夹以保留内容。完整模式删除分组时，可选择连同网址删除或仅移除分组。删除后 12 秒内可点击提示中的「撤回」恢复；后续网址编辑不会被旧撤回覆盖。

## 完整模式

完整模式按「时间与搜索 → 网址导航 → 常用工具 → 订阅与动态」排列。宽屏上时间与搜索并排，工具依次为待办、便签、计时器和天气；窄屏自动改为两列或单列。网址统一放在导航面板中，通过右上角添加按钮新增；「全部」展示所有网址。

页面只保留功能名称、操作提示和实际状态，已移除问候语、每日寄语及页脚口号。待办显示剩余数量，计时器显示未开始、计时中、已暂停或完成，便签显示保存状态和字数。订阅区域默认显示 RSS；GitHub 由用户切换后加载。未开启天气联网时，天气卡片显示设置入口和关闭状态。

## 主题色与壁纸联动

在「个性化设置 → 外观」中选择「主题色来源」：手动模式支持颜色选择器、六位 HEX 输入和推荐色；「跟随壁纸」模式会在更换壁纸时自动更新。颜色应用到按钮、设置面板、搜索框、Dock 托盘、图标底板与本地单色图形，并适配深浅主题。完整模式的导航和工具面板采用稳定的同色系底色，以明暗区分层次，避免壁纸穿透影响文字可读性；「面板底色强度」调整底色深浅。每种背景（面板、弹窗、输入框、搜索框和按钮）都单独计算黑白文字的对比度，并选择更高的一种。网站图标保留其独立灰度设置。

内置风景使用对应色板，自定义图片在本地读取缩小后的像素，选择主要色块；视频只在加载画面后取一次色，避免界面随播放闪动。「从当前壁纸重新取色」可手动触发更新。取色失败时保留上次颜色，提取过程不会上传图片。选取手动颜色会退出自动模式，迟到的取色结果不会覆盖手动选择。主题色来源、手动颜色和上次提取结果均本地保存，并随 JSON 备份恢复。

## 时钟背景与文字对比度

时间和日期默认使用轻微毛玻璃底板，黑色背景、不透明度 14%。在时间区域右键可打开「时钟外观」，也可直接切换「自动高对比文字」「白色文字」「黑色文字」；个性化设置的外观区也提供入口。底板颜色和不透明度可修改，设为 0% 可关闭底板；文字颜色可以手动选择。

自动模式会依据时钟所在区域的背景取样，合成页面遮罩和底板后，比较黑白文字的相对亮度对比度。内置风景使用对应的区域色板，自定义图片在本地采样并适配背景 cover 裁切；更换布局或调整窗口时重新计算。视频播放时最多每两秒检测一次当前画面，页面隐藏或选择手动字色后停止检测；主题色仍保持先前一次提取，不随视频反复变化。取样失败时沿用上次背景估值，右键可重新检测。字色模式、手动颜色和底板设置自动保存，并随 JSON 备份恢复。

## 两种布局与右键菜单

Dock 的右键菜单只包含该网址的打开 / 编辑 / 复制、添加快捷方式、新建文件夹、编辑模式和「Dock 设置」，不再混入壁纸、搜索引擎与完整主页操作。页面空白处仍提供主页的通用菜单。

Dock 支持文件夹：右键选择「新建文件夹」，填写名称并勾选网址；也可在编辑模式先勾选网址，再点击「新建文件夹」或通过「移入文件夹…」选择现有文件夹。封面按 2×2 排列展示前三个网址图标，第四格以「+N」显示剩余数量。文件夹可与其他图标一起拖动排序，结构与顺序自动保存，并随 JSON 备份恢复。

点击文件夹会打开居中聚焦面板，背景模糊；点击网址打开页面，点击其右上角 × 可移回 Dock。「整理内容」可改名、增减网址或从其他文件夹移入；「解散文件夹」和批量删除文件夹都保留其中的网址。支持空文件夹与嵌套文件夹。新建或整理时可选择「上级文件夹」，完整路径以 A/B 显示，表示 A 中的 B；打开文件夹后也可点击「新建子文件夹」。修改上级会保留整个子树，不能选择自身或后代作为上级，最多支持 32 层。Esc、点击面板外或关闭按钮可退出。完整模式同样保留文件夹层级，按当前分组筛选目录及其内容；点击「全部」查看所有目录和网址。文件夹内的网址可通过右键菜单编辑。

「Dock 设置」集中控制：停靠位置（底部 / 顶部 / 靠左 / 靠右 / 自由位置）、允许拖动、水平与垂直位置、图标大小、间距、最大宽度、托盘不透明度、悬停放大开关、倍率、影响范围、动画过渡时间、下方名称、名称字号和浮动名称。更改即时预览，点击「保存」后持久保存；关闭时若有修改，会询问保存、放弃修改或继续编辑。右侧数值可直接输入，统一显示两位小数；支持图标 16–160px、间距 0–160px、宽度 120–3840px、放大 1–4 倍、影响范围 20–600px、过渡 0–2000ms，位置与不透明度为 0–100%，名称字号为 8–32px。设置也随 JSON 备份恢复；旧备份自动补齐默认值。通用设置中提供 Dock 设置入口。Dock 图标尺寸与完整模式的图标尺寸独立。

开启「允许拖动位置」后，在极简模式拖动 Dock 左侧手柄即可自由移动，释放时保存；手柄也支持方向键微调，按住 Shift 加大步长。取消拖动会回到保存位置。位置按窗口比例保存，显示时限制在窗口范围内；窗口缩放后重新限制边界。恢复默认只重置 Dock 偏好，保留网址、分组和其他主页数据。

极简模式下，在底部 Dock 图标或托盘空白处右键，选择「编辑模式」。每个图标右上角出现复选框，点击图标本身也可选择，不会打开网址；编辑期间暂停悬停放大。Dock 上方提供已选数量、全选 / 取消全选、删除所选、导入浏览器书签和完成按钮。也可直接在 Dock 右键菜单选择「导入浏览器书签」，选择扩展导出的 JSON 后预览并按层级追加，无需切换完整模式。编辑模式下会显示可点击的下方名称，即使平时关闭名称显示也可编辑；点击名称可重命名网址或文件夹，保存后同步更新悬停提示、完整模式列表及文件夹标题，网址和分组不变。批量删除先显示确认窗口，确认后保存；取消则保留选择。点击「完成」、右键「退出编辑模式」或按 Esc 退出，切换布局也会清空临时选择；编辑状态不随刷新保存。

编辑模式下，可按住图标拖动排序：移动超过小幅阈值后显示浮动图标和原位占位，其他图标实时让位；靠近 Dock 两侧时自动横向滚动。在 Dock 内松手会保存新顺序，刷新、重新打开主页及恢复备份后保持；网址分组不变。复选框仍用于批量选择，拖动不会误触选择或打开网址。拖动中按 Esc、移出 Dock 后松手或取消触摸会恢复本次拖动前的顺序；退出编辑、切换布局也会取消未完成排序。

每次打开先进入极简模式：上方为独立的时钟日期区域，搜索框居中，Dock 默认位于底部，可在 Dock 设置中修改位置，带有半透明托盘。鼠标靠近时，当前及相邻图标根据距离平滑放大、上浮和推开；离开、点击图标、窗口失焦、页面进入后台、打开菜单或切换模式后复位；弹窗关闭自动恢复焦点不会再次放大，Tab 键聚焦仍支持放大。支持键盘聚焦，不在触摸移动或“减少动态效果”偏好下触发放大。名称可悬停查看；图标过多时可横向滑动，或将鼠标放在图标行上使用滚轮。搜索框聚焦、放大和背景模糊都不会改变时钟的位置或清晰度。页面刚打开会自动聚焦输入框，但不会立即模糊背景；点击、输入或按 `/` 后才启用聚焦效果。

鼠标悬停或键盘聚焦网站图标时显示自定义浮动名称，移开或打开菜单后隐藏。通过「Dock 设置 → 悬停与名称」可独立打开或关闭图标下方的常驻名称和悬停浮动名称；下方名称默认关闭，浮动提示默认开启。下方名称会随图标缩放、上浮和横向移动；名称字号可在 Dock 设置中通过滑块或数字输入调整，托盘空间随字号预留，浮动名称贴近图标定位。偏好会自动保存并随 JSON 备份恢复，完整模式的原有网站名称不受影响。

在搜索框外右键只打开操作菜单，保持当前模式；选择“展开完整主页”后才进入完整模式。展开后可使用时间、分类网址、天气、待办、便签和其他小组件。极简页面右上角有展开按钮，底部 Dock 不再放置展开入口；完整页面右上角的收起按钮、右键菜单中的“收起为极简主页”或 `Alt+Z` 均可切换模式。`Esc` 依次用于关闭菜单、退出搜索聚焦，或收起完整主页；有弹窗时优先按弹窗规则处理。模式切换不清除便签、网址或其他保存数据。

搜索框内右键仅显示“复制、粘贴、剪切、转到”。复制与剪切作用于选中文字；“转到”优先使用选中文字，否则使用整条输入，复用现有的网址直达 / 引擎搜索逻辑。浏览器禁止读取剪贴板时，会弹出手动粘贴窗口，可按 Ctrl+V（Mac 为 ⌘V）后确认。无选区时复制和剪切不可用，空输入时“转到”不可用。

搜索框外的右键菜单提供添加快捷方式、管理网址与分组、管理搜索引擎、更换壁纸和个性化设置。对网站图标右键，还可直接打开、编辑该网址或复制网址；便签等输入区域保留相应的复制、粘贴、剪切操作；弹窗内提供关闭窗口。页面区域的右键默认行为均被自定义菜单替换。

## 管理搜索引擎

右键菜单中选择“管理搜索引擎”，或通过“设置 → 搜索引擎 → 管理搜索引擎”进入。完整模式的搜索框下方管理图标、搜索框左侧引擎菜单底部也有管理入口。

点击“新增引擎”，填写名称和搜索网址，例如 `https://www.baidu.com/s?wd={query}`。用一个 `{query}` 代表关键词，支持放在路径或查询参数中，程序会自动编码中文及特殊字符。点击图标选择器可选择 18 个内置引擎图标或搜索、网页、阅读、购物、代码、灵感 6 个通用图形；新引擎默认使用放大镜。也可在自定义字段填写 Emoji 或文字，填写后切换为自定义字符模式，重新点击图形可切回。快捷指令可不填；填写时需为 1 至 8 位英文字母或数字，以字母开头，且不可重复，不区分大小写。

图标在搜索框、引擎菜单、快捷栏与管理列表中保持统一。旧配置中的默认引擎文字标识会自动升级为图形，用户自定义过的 Emoji / 文字标识保持不变。完整图标集位于 `assets/engines/`，预览见 `previews/engine-icons.png`；素材来源和说明见 `assets/engines/README.md`。

## Dock 新增图标如何保持统一

在 Dock 上右键选择「添加快捷方式」即可添加网站，极简模式不显示加号入口。填写网址后自动补全网站名称（优先网站声明的名称，其次网页标题，读取受限时使用域名），仍可手动修改，迟到的响应不会覆盖手动名称。自动尝试读取同站点页面声明的图标，未读到时使用 /favicon.ico、/apple-touch-icon.png。能读取像素时会保留并缓存原图，跨域限制导致不能读取像素时直接加载站点图标。网站图标共用薄荷色底板，默认仅应用 20% 灰度，保留大部分颜色；添加和编辑窗口可通过「图标灰度」滑块或数字输入调整到 0–100%（0% 原色、100% 黑白），预览即时变化，保存后随网站和备份保留。图标加载失败会回退本地图形，不影响保存网址。不会通过第三方 favicon 服务中转。

编辑窗口提供「自动获取网站图标」按钮，可为已有网址重新获取；手动选择矢量图形或上传图片会取消自动获取，避免迟到的网络响应覆盖手动选择。已有网址保留原图标，只有新增网址或主动点击获取时才启用。自动图标模式与成功缓存的图标都随 JSON 备份恢复；未缓存的站点图标需要联网，离线时显示本地图形。也可从图标选择器中改选 29 种本地矢量图形。

自定义上传功能保留，支持 5 MB 内的 PNG、JPG、WebP、GIF。透明图保留 alpha 轮廓；不透明图片会尝试去除平坦背景，提取图案后裁切并等比缩放为统一蒙版。Dock 始终用深绿色绘制该蒙版，不直接渲染原色图片；原色 128×128 缩略图、蒙版和所选图形一起保存及备份。建议使用透明底 PNG，复杂背景未必能提取出清晰轮廓；无法提取时自动显示通用图形，可改选预设或重新上传。旧上传图标会在浏览器支持解码时自动补充蒙版，转换期间也不会闪现彩色原图。

“恢复自动统一图标”可以清除上传覆盖。Dock 图标风格预览见 `previews/dock-icons.png`。

管理列表中可以编辑内置或自定义引擎，勾选“快捷栏”、设置默认引擎，并用上下箭头调整显示顺序。至少保留一个引擎，最多 64 个。删除当前引擎后会选中列表第一项。“恢复内置引擎”需要确认，只替换搜索引擎相关配置；请先备份自定义内容。

常用指令：`bd` 百度、`g` Google、`gh` GitHub、`yt` YouTube、`wk` 维基百科、`so` Stack Overflow、`gs` Google 学术。也可直接粘贴“指令 + 空格 + 关键词”后按回车。不同站点可能要求登录、验证码或具有地区访问限制；可在管理中调整网址模板。

## 数据与网络

设置、网址、便签和待办存储在 localStorage，上传壁纸存储在 IndexedDB。浏览器对本地文件的存储支持与隔离方式可能不同；更换浏览器、移动文件夹或清理浏览器数据后，原来的配置不一定可用。存储不可用或已满时页面会显示提示，请定期导出 JSON 备份，可在其他设备手动导入。图片 / 视频壁纸上限 30 MB，图标上传上限 5 MB 并缩放为 128×128。

之前通过 `http://127.0.0.1:4173` 保存的数据与本地文件模式相互隔离。若已有 JSON 备份，在设置中导入即可恢复。

天气使用 [Open-Meteo](https://open-meteo.com/)，城市搜索使用其 Geocoding API。天气联网默认关闭（旧设置同样默认关闭），在天气城市设置中主动开启后才请求天气和搜索城市；关闭会中止进行中的请求并忽略迟到的定位结果。定位、城市选择、旧数据加载及备份导入的坐标统一保留一位小数（纬度约 11 公里网格，经度间距随纬度变化），只保存和发送近似坐标。选择定位时仍由浏览器征求授权；服务商能看到近似坐标及网络 IP。备份导入后天气联网关闭，需重新主动开启。部分浏览器在本地文件模式下不开放定位，可改为搜索城市。GitHub 发现通过 GitHub REST API 加载，未登录请求存在限流。本地图形和已缓存图标可离线渲染；启用自动网站图标时会请求所填写的站点及其图标，不会向第三方 favicon 服务发送域名。字体使用系统字体；默认风景为项目内 SVG，无外部图片依赖。

RSS 直接从源站请求，不经过第三方代理，源站必须允许浏览器 CORS 访问；本地文件请求的 Origin 通常为 `null`，源站也需要允许这种请求。不要填写本机 `file://` 订阅地址，浏览器通常禁止脚本直接读取其他本地文件。未开放跨域的订阅源会显示明确失败提示。天气、GitHub、在线搜索仍需要互联网，快捷方式图标可离线显示，但无需运行自己的服务器；无网络时，时钟、导航管理、待办、便签、计时器、内置风景及备份功能仍可使用。壁纸视频受浏览器自动播放策略限制，无法播放时会显示提示。

本项目为纯静态应用，没有账号、云同步或后端，已移除本地服务器脚本。也可将上述页面文件直接放到任意静态托管平台。

## 验证

以下仅供开发验证，需要 Node.js；日常打开主页不需要 Node.js，也不需要安装测试依赖。完整测试中的 jsdom 仅为开发依赖：

```powershell
npm ci
npm test
```

无需安装依赖时可运行 `npm run test:core`，只执行核心测试。完整测试还使用 jsdom 在禁用网络、模拟剪贴板及弹窗的平台环境中执行实际页面脚本，覆盖布局切换和右键交互；它不能代替浏览器渲染、剪贴板权限与本地文件存储实测。验证详情见 [验证记录](verification.md)。

安全提示：便签、待办和 JSON 备份不加密，请勿存放密码或令牌。既有备份中的精确坐标不会被自动修改，建议重新导出并妥善处理旧备份。天气联网开关仅控制天气和城市搜索，GitHub、RSS 和主动搜索分别按用户操作联网。
